# hakeem-fe-service

Frontend for **حكيم (Hakeem)** — a React Native (Expo) medical appointment booking app for Patient, Doctor, and Assistant roles.

## Setup

```bash
npm install
cp .env.example .env
npx expo start
```

See `.env.example` for API and SignalR URL placeholders. Mock auth is enabled by default (`EXPO_PUBLIC_USE_MOCK_AUTH=true`).
